# Published artifacts

Every page in this repo, listed. RIA appends a row as part of publishing, on the
same branch as the page itself, so the two land in one merge — and
`.github/check_indexed.py` fails the build if a page ever shows up without one.

**No access codes here, ever.** The ciphertext is in this same public repo; a
code beside it would put both halves of the lock in one place, which is exactly
what sending the link and the code as separate messages is meant to prevent. The
check enforces that too.

The point of the list is accountability. Without it this is a pile of opaque
encrypted blobs: you can't tell which pages are still meant to be live, which
were one-off tests, or which you'd want revoked if a code ever leaked.
